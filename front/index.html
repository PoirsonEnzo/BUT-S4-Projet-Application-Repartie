Architecture

Ce qui a été fait

  • Service RMI exposant les restaurants et les réservations
  • Proxy HTTP faisant le lien entre le front et le service RMI
  • Proxy HTTP récupérant les incidents de circulation du Grand Nancy
  • Intégration des données ouvertes vélib directement depuis le front
  • Carte Leaflet avec markers restaurants, incidents et stations vélib
  • Formulaire de réservation depuis la carte

Technologies

  • Front : TypeScript, Leaflet, esbuild, webetu
  • Proxy : Java 11, HttpServer, client RMI
  • Back : Java 11, RMI, JDBC Oracle, charlemagne
  • Base de données : Oracle (charlemagne)
